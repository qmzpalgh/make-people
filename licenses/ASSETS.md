# Asset provenance

The upstream repository's Apache License 2.0 is in [LICENSE](../LICENSE). The following MakeHuman data has its own CC0 1.0 Universal dedication. CC0 permits modification and redistribution, including use in games. The MakeHuman project identifies the base mesh, targets, modifiers, and clothing as CC0 assets in section C of its licence. The full dedication is included in [MakeHuman-CC0.md](MakeHuman-CC0.md). The system pack lists these assets individually as **CC0**, and the selected fitting files include the CC0 notice. The mesh headers credit the MakeHuman contributors, including Data Collection AB, Joel Palmius, and Jonas Hauquier. Target headers also credit original contributor Manuel Bastioni. [System asset catalogue](https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html) · [CC0 system pack](https://files2.makehumancommunity.org/asset_packs/makehuman_system_assets/makehuman_system_assets_cc0.zip) · [Base mesh and target data](https://github.com/makehumancommunity/makehuman/tree/a8bc2d54ff0ac92e78ff71431b1023eda42bf482/makehuman/data)

The swept ponytail, gold hoops, interface icons, shaders, procedural maps, fitting pipeline and studio code were created for this project. The build uses geometry and displacement data from MakeHuman. Every shipped character texture is generated by the shaders or by `tools/fiber_maps.py`. Documentation previews are captures of the running Godot project.
